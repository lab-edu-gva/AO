## 3. Contenidos y explicación teórica
# 1. Qué son los requisitos del sistema
Antes de instalar una aplicación hay que comprobar si el equipo puede ejecutarla correctamente. Los **requisitos del sistema** describen las condiciones mínimas o recomendadas de hardware y software necesarias para utilizarla. No son una formalidad: ignorarlos puede provocar que el instalador no se ejecute, que el programa funcione lentamente, que falten funciones o que aparezcan errores.

Los requisitos mínimos indican el umbral para ejecutar el producto en condiciones limitadas. Los recomendados describen una configuración más adecuada para trabajar con comodidad. El significado exacto depende del fabricante, por lo que se debe consultar su documentación oficial.

# 2. Requisitos de hardware
- **Procesador (CPU):** arquitectura compatible y potencia suficiente. Puede indicarse una familia, generación o velocidad.
- **Memoria RAM:** espacio de trabajo temporal. Si falta memoria, el sistema puede recurrir al almacenamiento y ralentizarse.
- **Almacenamiento:** espacio para instalar el programa, actualizaciones, perfiles y archivos temporales.
- **Tarjeta gráfica y pantalla:** pueden exigirse capacidades concretas para interfaces o funciones visuales.
- **Periféricos:** cámara, micrófono, impresora u otros dispositivos si la aplicación los necesita.

# 3. Requisitos de software
Incluyen sistema operativo y versión, arquitectura de 32 o 64 bits cuando corresponda, bibliotecas, componentes, controladores, navegador compatible y permisos necesarios. Una aplicación puede ser compatible con Windows 11 y no con una versión antigua; también puede ofrecer instaladores diferentes para Windows, macOS y GNU/Linux.

# 4. Compatibilidad
La compatibilidad no se limita a que el instalador arranque. Hay que comprobar que las funciones necesarias trabajan correctamente, que los archivos se abren y guardan en formatos esperados, que los periféricos funcionan y que la aplicación convive con el resto del sistema.

También hay que distinguir compatibilidad del fabricante y funcionamiento observado. Una aplicación puede arrancar en un sistema no soportado, pero no existe garantía de estabilidad ni soporte. En un entorno profesional debe priorizarse una configuración oficialmente admitida.

# 5. Inventario antes de instalar
Un inventario técnico recoge las características relevantes del equipo: modelo, CPU, RAM, espacio libre, sistema operativo, arquitectura, periféricos y aplicaciones existentes. Debe obtenerse con herramientas del sistema o inventario corporativo, sin modificar configuraciones ni recopilar datos personales innecesarios.

## 4. Ejemplo práctico guiado
## Ejemplo guiado: verificar un equipo Windows
1. Abre **Configuración > Sistema > Acerca de** y registra edición/versión de Windows, procesador, RAM y tipo de sistema.
2. Abre **Este equipo** y consulta el espacio libre de la unidad donde se instalaría el programa.
3. Identifica periféricos requeridos en el escenario.
4. Consulta la página oficial de requisitos de la aplicación.
5. Compara cada requisito con el equipo y clasifica el resultado: cumple, no cumple o requiere comprobación.
6. No descargues instaladores de páginas de terceros para “probar”: utiliza la fuente oficial y las instrucciones del centro.

Ejemplo de tabla: requisito de RAM 8 GB; equipo 16 GB; resultado cumple. Sistema operativo compatible Windows 11; equipo Windows 10; resultado no cumple o requiere verificar compatibilidad exacta.

## 7. Material del alumnado: actividades
## Actividad 1. Matriz de compatibilidad
Prepara una tabla con cinco requisitos de una aplicación ofimática real y los datos de un equipo del aula. Indica la fuente de cada requisito y concluye si la instalación es viable.

## Actividad 2. Diagnóstico
Un programa requiere 8 GB de RAM, 4 GB libres y Windows 11. El equipo tiene 8 GB de RAM, 2 GB libres y Windows 11. Explica qué cumple, qué no y qué actuación sería adecuada antes de instalar.

## Actividad 3. Requisitos ocultos
Explica por qué además de CPU y RAM pueden ser importantes la arquitectura, los permisos, los controladores y la conexión a Internet.
