## 3. Contenidos y explicación teórica
# 1. ¿Qué es una aplicación informática?
Una **aplicación informática** es un programa o conjunto de programas diseñado para que una persona realice una tarea concreta mediante un dispositivo informático. El sistema operativo administra el equipo y proporciona servicios; las aplicaciones utilizan esos servicios para resolver necesidades del usuario. Por ejemplo, el sistema operativo gestiona archivos, memoria y dispositivos, mientras que LibreOffice Writer permite crear documentos.

Conviene distinguir tres conceptos:
- **Software de sistema:** sistema operativo, controladores y utilidades necesarias para que el equipo funcione.
- **Software de aplicación:** programas orientados a tareas del usuario, como escribir, calcular, navegar o editar imágenes.
- **Software de programación:** herramientas para crear otros programas, como editores de código, compiladores o depuradores.

Una aplicación puede instalarse localmente, ejecutarse desde un navegador o combinar ambos modelos. Una aplicación de escritorio se instala en el equipo; una aplicación web se utiliza mediante un navegador y normalmente depende de servicios remotos; una aplicación móvil está adaptada a teléfonos y tabletas.

# 2. Aplicaciones ofimáticas y suites
La **ofimática** reúne herramientas digitales para producir, organizar, comunicar y compartir información en actividades administrativas y profesionales. Una suite ofimática agrupa varias aplicaciones que comparten fabricante, interfaz o formatos de intercambio. Puede incluir procesador de textos, hoja de cálculo, presentaciones, gestión de bases de datos y herramientas de comunicación. En esta unidad nos centramos en reconocerlas y seleccionar soluciones; el estudio detallado de cada aplicación corresponde a otras unidades.

Ejemplos habituales: LibreOffice, Microsoft 365 y Google Workspace. No son idénticos: pueden diferir en modelo de instalación, coste, colaboración, compatibilidad de formatos, administración y dependencia de Internet.

# 3. Cómo elegir una solución
La elección no debe basarse únicamente en que una aplicación sea conocida o gratuita. Hay que identificar la necesidad, los usuarios, el entorno técnico, los formatos que se intercambiarán, las condiciones de licencia, la seguridad, la accesibilidad, el soporte y el coste total.

**Ejemplo:** un pequeño centro educativo necesita redactar documentos, preparar hojas de cálculo y compartir archivos. Puede valorar una suite instalada en los equipos, una solución web o una combinación. Si trabaja a menudo sin conexión, la disponibilidad local será importante. Si varias personas editan simultáneamente, la colaboración en línea tendrá más peso. Si recibe documentos de terceros, debe comprobar la compatibilidad de formatos.

# 4. Familias de aplicaciones y escenarios
- Ofimática: documentos, cálculos y presentaciones.
- Navegadores: acceso a servicios web.
- Comunicación: correo, mensajería y videoconferencia.
- Gestión: facturación, inventario o relación con clientes.
- Seguridad y mantenimiento: antivirus, copias y diagnóstico.
- Diseño y multimedia: edición de imagen, audio o vídeo.

Una misma necesidad puede resolverse con productos distintos. La propuesta profesional debe justificar por qué una opción se adapta mejor al contexto y no limitarse a enumerar marcas.

## 4. Ejemplo práctico guiado
## Ejemplo guiado: comparar dos suites
1. Define el escenario: 15 equipos, documentos compartidos y algunos usuarios que trabajan sin conexión.
2. Anota necesidades imprescindibles: procesador de textos, hoja de cálculo, presentaciones, formatos compatibles y facilidad de actualización.
3. Añade necesidades deseables: edición simultánea, almacenamiento en nube, administración centralizada y soporte.
4. Compara dos alternativas reales usando documentación oficial. No supongas que una función existe: compruébala.
5. Redacta una recomendación de un párrafo que incluya ventajas, limitaciones y condiciones.

La comparación debe separar hechos verificables (por ejemplo, sistemas operativos compatibles) de valoraciones (por ejemplo, interfaz más sencilla).

## 7. Material del alumnado: actividades
## Actividad 1. Clasificación
Clasifica diez programas que conozcas en software de sistema, aplicación o programación. Para cada uno, indica qué necesidad resuelve y si es de escritorio, web o móvil.

## Actividad 2. Propuesta de suite
Una asociación necesita crear documentos, presupuestos y presentaciones. Tiene equipos modestos, presupuesto limitado y conexión a Internet irregular. Propón qué características debería cumplir su suite. No elijas por marca: justifica los requisitos.

## Actividad 3. Vocabulario
Explica con tus palabras las diferencias entre aplicación, suite, sistema operativo, aplicación web y aplicación de escritorio.

## 8. Preguntas de repaso y preparación del examen
- ¿Qué diferencia existe entre software de sistema y software de aplicación?
- ¿Qué aplicaciones puede incluir una suite ofimática?
- ¿Qué ventajas y limitaciones tiene una aplicación web frente a una instalada?
- ¿Qué criterios utilizarías para recomendar una suite a una empresa?
- ¿Por qué no basta con elegir el programa que tenga más funciones?
