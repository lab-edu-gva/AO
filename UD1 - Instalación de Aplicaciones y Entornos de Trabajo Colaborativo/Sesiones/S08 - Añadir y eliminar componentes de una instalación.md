# Sesión 08 – Añadir y eliminar componentes de una instalación

> **Material de estudio del alumnado.** Esta sesión está preparada para su estudio y trabajo; su estado no implica que ya se haya impartido.

## 1. Objetivos de aprendizaje
Al finalizar esta sesión deberías ser capaz de explicar los conceptos desarrollados, aplicar el procedimiento guiado y resolver las actividades propuestas justificando tus decisiones.

## 2. Relación curricular
- **Unidad:** Instalación de Aplicaciones y Entornos de Trabajo Colaborativo.
- **Resultados de aprendizaje:** RA1.
- **Criterios trabajados:** RA1.f, RA1.c, RA1.e.

## 3. Contenidos y explicación teórica
# 1. Instalación modular
Muchas aplicaciones permiten elegir componentes durante la instalación o modificarlos después. Un componente puede ser un módulo funcional, un idioma, una extensión, un controlador, una herramienta auxiliar o una integración con otro programa. La instalación modular permite adaptar el software a las necesidades reales.

# 2. Añadir componentes
Añadir un componente puede habilitar una función que no estaba instalada. Antes de hacerlo hay que comprobar que el componente pertenece al producto, que es compatible con la versión y que la licencia permite utilizarlo. También se debe valorar el espacio, las dependencias y el origen del paquete.

# 3. Eliminar componentes
Eliminar un módulo innecesario puede liberar espacio o reducir superficie de ataque y mantenimiento. Sin embargo, quitar un componente compartido o una dependencia puede afectar a otras funciones. Hay que revisar las advertencias del asistente y comprobar el resultado.

# 4. Modificar, reparar y desinstalar
- **Modificar:** cambiar los componentes instalados.
- **Reparar:** intentar restaurar archivos o configuraciones dañadas.
- **Desinstalar:** retirar la aplicación mediante el mecanismo previsto.

Desinstalar no siempre elimina documentos del usuario, perfiles, configuraciones o datos almacenados. Antes de hacerlo hay que identificar qué información debe conservarse. Tampoco se deben borrar manualmente carpetas del programa como sustituto de una desinstalación correcta.

# 5. Dependencias y consecuencias
Una función puede depender de otros módulos. Por ejemplo, una aplicación puede necesitar un componente de idioma o una extensión para abrir cierto formato. Eliminarlo puede provocar que una función deje de estar disponible. La gestión correcta requiere conocer el objetivo, registrar el cambio y realizar una prueba posterior.

## 4. Ejemplo práctico guiado
## Ejemplo guiado: modificar una instalación
1. Identifica la aplicación y su versión.
2. Consulta qué componentes están instalados y cuáles se necesitan.
3. Comprueba requisitos, licencia y dependencias del componente.
4. Abre el mecanismo oficial de modificación del programa o del sistema.
5. Selecciona únicamente el componente autorizado.
6. Aplica los cambios.
7. Abre la aplicación y prueba la función asociada.
8. Registra el componente añadido o retirado y el resultado.

Si el asistente advierte de que se eliminarán funciones relacionadas, detente y revisa el impacto antes de confirmar.

## 7. Material del alumnado: actividades
## Actividad 1. Decisión técnica
Un usuario solicita eliminar un módulo que ocupa espacio, pero otro departamento afirma que lo utiliza. Describe cómo recopilarías información y cómo decidirías.

## Actividad 2. Diferencias
Explica con un ejemplo la diferencia entre modificar, reparar y desinstalar una aplicación.

## Actividad 3. Inventario de componentes
Diseña una ficha con componente, función, versión, dependencias, motivo de instalación y prueba posterior.

## 8. Preguntas de repaso y preparación del examen
- ¿Qué es un componente opcional?
- ¿Qué riesgos tiene eliminar una dependencia?
- ¿Qué diferencia existe entre modificar y reparar?
- ¿Por qué desinstalar no implica necesariamente borrar los datos del usuario?
- ¿Qué comprobaciones se realizan tras modificar una instalación?

## 9. Resumen de estudio
En esta sesión se han trabajado los conceptos y procedimientos necesarios para comprender **añadir y eliminar componentes de una instalación**. Para preparar el examen, debes poder definir los términos principales, explicar por qué se realiza cada paso, identificar riesgos y justificar una actuación técnica adecuada. No memorices únicamente listas: relaciona cada decisión con el problema que evita o resuelve.
