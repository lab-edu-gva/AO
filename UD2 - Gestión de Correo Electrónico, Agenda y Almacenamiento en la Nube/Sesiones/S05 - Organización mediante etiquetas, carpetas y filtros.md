# S05 - Organización mediante carpetas, etiquetas y filtros

## 1. Introducción

En una empresa, el correo electrónico puede convertirse en una de las principales fuentes de información y comunicación.

Un trabajador puede recibir diariamente mensajes de clientes, proveedores, compañeros, responsables y servicios externos.

Si todos los mensajes permanecen mezclados en la bandeja de entrada, encontrar información puede resultar complicado.

Para solucionar este problema, los servicios de correo incorporan herramientas que permiten organizar los mensajes:

- Carpetas.
    
- Etiquetas.
    
- Marcadores.
    
- Filtros.
    
- Reglas automáticas.
    
- Categorías.
    

En esta sesión aprenderemos a utilizar estos mecanismos para mantener el correo organizado y reducir el tiempo dedicado a tareas repetitivas.

## 2. Organización mediante carpetas

Una carpeta es un espacio utilizado para agrupar mensajes relacionados según un criterio.

Podemos crear carpetas para clasificar los mensajes por:

- Departamento.
    
- Cliente.
    
- Proveedor.
    
- Tipo de documento.
    
- Proyecto.
    
- Estado de una tarea.
    

### 2.1. Ejemplo de organización empresarial

Imagina que trabajas en el departamento de administración de una empresa.

Podrías crear la siguiente estructura:

```
CORREO
│
├── CLIENTES
│   ├── Pedidos
│   └── Consultas
│
├── PROVEEDORES
│   ├── Facturas
│   └── Presupuestos
│
├── ADMINISTRACIÓN
│   ├── Nóminas
│   └── Documentación
│
├── REUNIONES
│
└── PENDIENTES
```

Esta estructura permite localizar rápidamente los mensajes.

### 2.2. Carpetas principales y subcarpetas

Podemos organizar las carpetas mediante diferentes niveles.

Una carpeta principal puede contener otras carpetas llamadas subcarpetas.

Por ejemplo:

- Proveedores es una carpeta principal.
    
- Facturas es una subcarpeta.
    
- Presupuestos es otra subcarpeta.
    

Esta organización jerárquica permite clasificar la información con mayor precisión.

### 2.3. Crear una carpeta

El procedimiento depende del servicio de correo utilizado, pero normalmente consiste en:

1. Acceder al panel de navegación.
    
2. Buscar la opción de crear carpeta.
    
3. Escribir un nombre.
    
4. Confirmar la creación.
    
5. Seleccionar los mensajes que queremos guardar.
    
6. Utilizar la opción de mover.
    

Algunos servicios permiten crear carpetas desde el menú contextual o desde la configuración.

### 2.4. Mover y copiar mensajes

Es importante distinguir entre mover y copiar.

**Mover:**

Traslada el mensaje a otra ubicación.

**Copiar:**

Crea otra copia del mensaje cuando el servicio ofrece esta posibilidad.

En algunos sistemas de correo, las etiquetas permiten conseguir una clasificación múltiple sin necesidad de duplicar el mensaje.

## 3. Organización mediante etiquetas

Una etiqueta es una marca que permite clasificar un mensaje según determinadas características.

Las etiquetas pueden representar:

- Un departamento.
    
- Un proyecto.
    
- Una prioridad.
    
- Un estado.
    
- Un tipo de comunicación.
    

Por ejemplo, un correo puede tener las etiquetas:

- Cliente.
    
- Urgente.
    
- Pendiente de respuesta.
    

Esto permite identificar el mensaje desde diferentes perspectivas.

### 3.1. Ejemplo de clasificación mediante etiquetas

Imagina que recibes un mensaje de un cliente que necesita una respuesta urgente.

Podemos asignarle las siguientes etiquetas:

|Etiqueta|Motivo|
|---|---|
|Cliente|Identifica el origen de la comunicación.|
|Urgente|Indica que requiere atención prioritaria.|
|Pendiente|Indica que todavía debemos responder.|

### 3.2. Colores de las etiquetas

Algunos servicios permiten asignar colores a las etiquetas.

Esto facilita reconocer visualmente los mensajes.

Por ejemplo:

- Rojo: urgente.
    
- Azul: clientes.
    
- Verde: facturas.
    
- Amarillo: pendiente.
    

Los colores son una convención organizativa. No existe una obligación de utilizar unos colores determinados.

### 3.3. Ventajas de las etiquetas

- Facilitan la clasificación.
    
- Permiten identificar mensajes rápidamente.
    
- Pueden combinarse varias etiquetas.
    
- Ayudan a organizar grandes cantidades de mensajes.
    
- Facilitan la búsqueda posterior.
    

### 3.4. Diferencias entre carpetas y etiquetas

|Característica|Carpetas|Etiquetas|
|---|---|---|
|Función|Agrupar mensajes en ubicaciones.|Clasificar mensajes mediante marcas.|
|Organización|Jerárquica mediante subcarpetas.|Mediante categorías o atributos.|
|Clasificación múltiple|Depende del sistema.|Habitualmente permite varias etiquetas.|
|Ejemplo|Proveedores/Facturas.|Urgente, Pendiente, Cliente.|

No todos los servicios implementan estas funciones de la misma manera.

Por ejemplo, Gmail utiliza etiquetas como mecanismo principal de clasificación, mientras que otros clientes ofrecen carpetas tradicionales.

## 4. ¿Qué es un filtro de correo electrónico?

Un filtro es una herramienta que permite aplicar automáticamente determinadas acciones a los mensajes que cumplen unas condiciones.

En lugar de clasificar manualmente cada correo, podemos configurar reglas para que el sistema realice el trabajo.

### 4.1. ¿Cómo funciona un filtro?

Un filtro funciona mediante dos elementos:

1. Condiciones.
    
2. Acciones.
    

**Condición:** determina qué mensajes deben cumplir una regla.

**Acción:** indica qué debe hacer el sistema cuando encuentra un mensaje que cumple esa condición.

### 4.2. Ejemplo sencillo

Imagina que recibes todas las facturas desde la dirección:

`facturas@proveedor.com`

Podemos crear un filtro con la siguiente configuración:

**Condición:**

El remitente es `facturas@proveedor.com`.

**Acción:**

Aplicar la etiqueta `Facturas`.

De esta manera, cada vez que llegue un mensaje de esa dirección, el sistema podrá clasificarlo automáticamente.

### 4.3. Condiciones habituales

Los filtros pueden utilizar diferentes condiciones.

|Condición|Ejemplo|
|---|---|
|Remitente|Mensajes de `proveedor@empresa.com`.|
|Destinatario|Mensajes enviados a `administracion@empresa.com`.|
|Asunto|Mensajes que contienen la palabra factura.|
|Palabras clave|Mensajes que contienen presupuesto.|
|Tamaño|Mensajes superiores a un tamaño determinado.|
|Adjuntos|Mensajes que contienen archivos adjuntos.|

Las condiciones disponibles dependen del servicio de correo.

### 4.4. Acciones habituales

Cuando un mensaje cumple las condiciones de un filtro, podemos realizar diferentes acciones.

|Acción|Resultado|
|---|---|
|Aplicar etiqueta|Clasifica el mensaje.|
|Mover a carpeta|Guarda el mensaje en una ubicación.|
|Marcar como leído|Cambia su estado.|
|Destacar|Marca el mensaje como importante.|
|Archivar|Lo retira de la bandeja de entrada.|
|Eliminar|Lo envía a la papelera.|
|Marcar como spam|Lo clasifica como correo no deseado.|
|Reenviar|Envía el mensaje a otra dirección, si el servicio lo permite.|

Debemos tener especial cuidado con las acciones automáticas que eliminan, archivan o reenvían mensajes.

Una regla mal configurada puede provocar que perdamos de vista comunicaciones importantes.

## 5. Crear filtros en Gmail: ejemplo práctico

Gmail permite crear filtros para automatizar la organización del correo.

El procedimiento general es el siguiente:

### Paso 1. Acceder a la búsqueda avanzada

Abrimos Gmail y utilizamos las opciones de búsqueda avanzada.

Podemos localizar el icono de opciones de búsqueda situado junto al cuadro de búsqueda.

### Paso 2. Definir las condiciones

Imagina que queremos organizar los mensajes de un proveedor.

Introducimos:

- De: `facturas@proveedor.com`
    
- Asunto: `Factura`
    

Estas condiciones permiten localizar mensajes que cumplan los criterios establecidos.

### Paso 3. Crear el filtro

Seleccionamos la opción para crear un filtro.

### Paso 4. Elegir las acciones

Podemos configurar, por ejemplo:

- Aplicar la etiqueta `Facturas`.
    
- No marcar como spam.
    
- Aplicar también el filtro a las conversaciones existentes, si queremos clasificar mensajes anteriores.
    

### Paso 5. Guardar

Una vez configurado, guardamos el filtro.

A partir de ese momento, los mensajes que cumplan las condiciones podrán recibir automáticamente las acciones establecidas.

> Los nombres y opciones concretas pueden variar con las actualizaciones de Gmail y de otros proveedores.

## 6. Ejemplos de automatización en una empresa

Vamos a estudiar diferentes situaciones en las que los filtros pueden ahorrar tiempo.

### 6.1. Organizar facturas

**Situación:**

Una empresa recibe facturas de diferentes proveedores.

**Condición:**

El mensaje procede de una dirección concreta.

**Acción:**

Aplicar la etiqueta `Facturas`.

### 6.2. Identificar mensajes urgentes

**Situación:**

El departamento de soporte recibe mensajes cuyo asunto contiene la palabra `URGENTE`.

**Condición:**

El asunto contiene `URGENTE`.

**Acción:**

Aplicar la etiqueta `Prioridad alta`.

### 6.3. Organizar comunicaciones de clientes

**Situación:**

El departamento comercial recibe mensajes desde una dirección determinada.

**Condición:**

El remitente pertenece a un cliente.

**Acción:**

Aplicar la etiqueta `Clientes`.

### 6.4. Separar comunicaciones informativas

**Situación:**

Un trabajador recibe boletines informativos de diferentes servicios.

**Condición:**

El mensaje procede de una dirección conocida.

**Acción:**

Aplicar una etiqueta específica o moverlo a una carpeta de comunicaciones informativas.

### 6.5. Precaución con los filtros

No debemos crear filtros demasiado generales.

Por ejemplo, una regla que archive todos los mensajes que contienen la palabra `factura` podría ocultar una factura importante que necesita revisión.

Antes de activar un filtro debemos comprobar qué mensajes puede afectar.

## 7. Prioridad y seguimiento de mensajes

Además de clasificar los mensajes, necesitamos identificar cuáles requieren una actuación.

Podemos utilizar diferentes mecanismos.

### 7.1. Destacar mensajes

Permite marcar un correo para localizarlo posteriormente.

Es útil para identificar:

- Facturas pendientes.
    
- Solicitudes importantes.
    
- Comunicaciones que requieren respuesta.
    
- Información que debemos consultar más adelante.
    

### 7.2. Marcar como importante

Algunos servicios incorporan indicadores de importancia.

Estos indicadores permiten diferenciar mensajes que consideramos prioritarios.

La importancia puede determinarse manualmente o mediante sistemas automáticos.

### 7.3. Marcar como no leído

Podemos utilizar esta opción para recordar que debemos revisar un mensaje.

Por ejemplo:

Recibimos una solicitud de presupuesto, la abrimos y comprobamos que necesitamos consultar los precios antes de responder.

Podemos marcar el mensaje como no leído para recordar que sigue pendiente.

### 7.4. No confundir importancia y urgencia

Un mensaje importante puede no requerir una respuesta inmediata.

Un mensaje urgente puede requerir una actuación rápida aunque su contenido no tenga gran relevancia a largo plazo.

La organización del correo debe ayudarnos a distinguir ambas situaciones.

## 8. Ejemplo guiado: crear un sistema de organización

Imagina que trabajas en el departamento administrativo de una empresa.

Recibes mensajes de tres tipos:

1. Facturas de proveedores.
    
2. Solicitudes de clientes.
    
3. Comunicaciones internas.
    

Vamos a diseñar un sistema de organización.

### Paso 1. Crear categorías

Creamos las siguientes carpetas o etiquetas:

- Facturas.
    
- Clientes.
    
- Internos.
    
- Pendientes.
    

### Paso 2. Definir los filtros

|Condición|Acción|
|---|---|
|Remitente: `facturas@proveedor.com`|Aplicar etiqueta Facturas.|
|Remitente: `cliente@empresa.com`|Aplicar etiqueta Clientes.|
|Remitente: `rrhh@empresa.com`|Aplicar etiqueta Internos.|

### Paso 3. Identificar los mensajes pendientes

Cuando un mensaje requiera una actuación, podemos añadir la etiqueta `Pendientes`.

### Paso 4. Revisar los resultados

Comprobamos que:

- Las facturas aparecen clasificadas.
    
- Las solicitudes de clientes están identificadas.
    
- Las comunicaciones internas se encuentran organizadas.
    
- Los mensajes pendientes son fáciles de localizar.
    

El resultado es un sistema que reduce la clasificación manual y facilita el trabajo diario.

## 9. Actividades prácticas

### Actividad 1. Diseñar una estructura de carpetas

Imagina que trabajas en una empresa que tiene los siguientes tipos de comunicaciones:

- Facturas.
    
- Clientes.
    
- Proveedores.
    
- Recursos humanos.
    
- Informática.
    
- Reuniones.
    

Diseña una estructura de carpetas que permita organizar estos mensajes.

Debe contener:

- Al menos cuatro carpetas principales.
    
- Al menos tres subcarpetas.
    
- Una explicación de su utilidad.
    

### Actividad 2. Diseñar etiquetas

Crea cinco etiquetas que utilizarías para organizar tu correo profesional.

Para cada etiqueta indica:

- Nombre.
    
- Color propuesto.
    
- Qué mensajes clasificarías.
    
- Por qué sería útil.
    

### Actividad 3. Diseñar filtros

Una empresa recibe los siguientes mensajes:

|Remitente|Asunto|
|---|---|
|[facturas@proveedor.com](mailto:facturas@proveedor.com)|Factura noviembre|
|[clientes@empresa.com](mailto:clientes@empresa.com)|Consulta sobre pedido|
|[rrhh@empresa.com](mailto:rrhh@empresa.com)|Información de vacaciones|
|[soporte@empresa.com](mailto:soporte@empresa.com)|Incidencia informática|
|[facturas@proveedor.com](mailto:facturas@proveedor.com)|Factura diciembre|

Diseña al menos tres filtros.

Para cada filtro debes indicar:

1. Condición.
    
2. Acción.
    
3. Resultado esperado.
    

### Actividad 4. Analizar filtros incorrectos

Un trabajador crea un filtro con estas características:

- Condición: todos los mensajes que contengan la palabra `importante`.
    
- Acción: eliminar automáticamente el mensaje.
    

Explica:

1. Qué problema puede provocar.
    
2. Por qué la condición es demasiado general.
    
3. Qué alternativa sería más adecuada.
    

### Actividad 5. Práctica con un servicio de correo

Si dispones de una cuenta de correo de prácticas:

1. Crea una etiqueta o carpeta llamada `Prácticas`.
    
2. Crea una segunda llamada `Pendientes`.
    
3. Localiza un mensaje de prueba.
    
4. Clasifícalo en `Prácticas`.
    
5. Configura un filtro sencillo, si el servicio lo permite.
    
6. Comprueba su funcionamiento con un mensaje de prueba.
    

No utilices cuentas reales de terceros ni modifiques filtros de una cuenta profesional sin autorización.
