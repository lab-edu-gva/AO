# S07 - Proyecto de integración: presentación técnica

## Reto
Diseña una presentación técnica dirigida a alumnado de 1.º SMR. Debe explicar un tema informático con rigor, claridad y un diseño coherente.

## Temas
Elige uno:
- Cómo funciona una red local.
- Componentes internos de un ordenador.
- Amenazas y medidas de protección.
- Copias de seguridad.
- Sistemas de almacenamiento.
- Mantenimiento preventivo de equipos.

## Fase 1. Planificación
Antes de diseñar:
1. Define el público.
2. Escribe el objetivo de la presentación.
3. Resume tres ideas que el público debe recordar.
4. Prepara un guion de entre siete y nueve diapositivas.
5. Identifica qué recursos visuales necesitas.

## Fase 2. Construcción
La presentación debe incluir:
- Portada.
- Introducción y objetivo.
- Desarrollo organizado en bloques.
- Al menos una comparación, proceso o diagrama.
- Imágenes pertinentes.
- Conclusiones.
- Fuentes consultadas, cuando se utilicen recursos externos.

## Fase 3. Diseño
Aplica:
- Jerarquía clara entre títulos y contenido.
- Tipografía legible y consistente.
- Paleta limitada.
- Contraste suficiente.
- Alineación y espacios adecuados.
- Patrón o plantilla común.
- Recursos gráficos con una finalidad explicativa.

## Fase 4. Revisión técnica
Comprueba:
- Que todas las diapositivas mantienen un orden lógico.
- Que no hay errores ortográficos.
- Que las imágenes no están deformadas.
- Que el texto puede leerse desde cierta distancia.
- Que los archivos externos necesarios están disponibles.
- Que la presentación se reproduce correctamente.

## Fase 5. Entrega
Entrega:
- Archivo editable ODP.
- Exportación PDF.
- Guion de planificación.
- Breve autoevaluación: tres decisiones de diseño que hayas tomado y por qué.

## Reto de ampliación
Prepara una versión alternativa de una diapositiva especialmente compleja. Compara las dos versiones y justifica cuál comunica mejor la información.

## Autoevaluación
- [ ] He planificado antes de diseñar.
- [ ] La secuencia tiene sentido.
- [ ] Cada diapositiva cumple una función.
- [ ] El texto tiene jerarquía.
- [ ] Las imágenes aportan información.
- [ ] El color se utiliza con intención.
- [ ] La presentación mantiene coherencia.
- [ ] He comprobado el archivo y la exportación.
