# S05 - Color, contraste y consistencia visual

## Objetivos
Seleccionar una paleta de color funcional, garantizar el contraste entre texto y fondo y aplicar un sistema visual coherente a varias diapositivas.

## 1. El color como herramienta de comunicación
El color puede:
- Diferenciar categorías.
- Señalar advertencias.
- Destacar datos.
- Crear identidad visual.
- Ayudar a reconocer elementos relacionados.

No debe utilizarse de forma aleatoria. Asigna una función a cada color y mantén esa función en toda la presentación.

## 2. Paleta de color
Una paleta es un conjunto limitado de colores que se utilizan de forma coordinada. Como punto de partida puedes definir:
- Color principal: títulos o elementos dominantes.
- Color secundario: bloques y elementos complementarios.
- Color de acento: llamadas de atención.
- Colores neutros: fondos y texto.

No es obligatorio utilizar siempre cuatro colores; lo importante es que exista una lógica y no se acumulen colores sin función.

## 3. Contraste entre texto y fondo
El contraste permite distinguir el texto del fondo. Comprueba:
- Texto oscuro sobre fondo claro o viceversa.
- Que el color de acento no se utilice para párrafos extensos.
- Que los enlaces o elementos destacados se distingan también por su posición o forma, no solo por el color.
- Que la información siga siendo comprensible si el público no distingue algún color.

## 4. Fondos y legibilidad
Los fondos con fotografías, texturas o patrones pueden competir con el texto. Si necesitas colocar texto sobre una imagen, utiliza una zona limpia o un bloque de fondo que asegure la lectura.

## 5. Consistencia visual
Una presentación coherente mantiene decisiones comunes:
- Mismo estilo de títulos.
- Paleta limitada.
- Márgenes similares.
- Alineaciones repetibles.
- Uso consistente de iconos y formas.
- Pie o numeración, si aporta utilidad.

Consistencia no significa que todas las diapositivas deban ser idénticas. Se puede variar la distribución manteniendo las mismas reglas visuales.

## 6. Actividad principal: sistema visual para una presentación de ciberseguridad
Define una paleta para una presentación titulada **«Buenas prácticas de ciberseguridad en el aula»**.

Prepara una diapositiva de muestra con:
- Título.
- Un bloque de información.
- Una advertencia.
- Un dato destacado.
- Un fondo.

Anota qué función tiene cada color. Después aplica el mismo sistema a otras dos diapositivas.

## 7. Reto de ampliación
Intercambia la presentación con un compañero. Sin explicarle tus decisiones, pídele que identifique:
- Qué elemento es el título.
- Qué información es una advertencia.
- Qué dato es el más importante.
Si no lo identifica rápidamente, revisa la jerarquía y el contraste.

## 8. Entrega

## 9. Preguntas
1. ¿Qué es una paleta de color?
2. ¿Qué función puede tener un color de acento?
3. ¿Por qué el contraste es importante?
4. ¿Cómo puede una presentación ser coherente sin repetir exactamente el mismo diseño?
5. ¿Qué alternativa existe cuando no conviene transmitir una diferencia únicamente mediante el color?
