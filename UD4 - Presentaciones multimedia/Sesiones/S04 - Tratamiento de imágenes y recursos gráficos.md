# S04 - Tratamiento de imágenes y recursos gráficos

## Objetivos
Insertar y editar imágenes, conservar sus proporciones, recortarlas con intención y utilizar formas y diagramas para representar información técnica.

## 1. Elegir una imagen adecuada
Una imagen debe cumplir una función: explicar, identificar, comparar, contextualizar o aportar evidencia. Antes de insertarla, valora:
- Relación con el contenido.
- Resolución suficiente para el tamaño de uso.
- Claridad del elemento principal.
- Ausencia de elementos irrelevantes.
- Permiso o licencia para reutilizarla.

No utilices una imagen solo para rellenar espacio. Si no aporta información, probablemente sobra.

## 2. Resolución y proporciones
Una imagen digital está formada por píxeles. Si se amplía demasiado, puede pixelarse. Si se modifica su anchura y altura de forma independiente, puede deformarse.

Al redimensionar:
- Arrastra preferentemente desde las esquinas.
- Comprueba que las proporciones se mantienen.
- Evita ampliar imágenes pequeñas por encima de su resolución útil.
- Recorta cuando sea necesario centrar la atención.

## 3. Recorte y encuadre
Recortar significa eliminar partes de una imagen para mejorar el encuadre. No es lo mismo que reducir el tamaño del objeto en la diapositiva.
Un buen recorte:
- Elimina zonas sin interés.
- Mantiene el contexto necesario.
- Dirige la mirada al elemento importante.
- No elimina información esencial.

## 4. Formas, líneas y conectores
Las formas pueden representar componentes, procesos o relaciones. Los conectores son útiles para señalar conexiones entre elementos. Utiliza un significado consistente: por ejemplo, el mismo tipo de flecha para el mismo tipo de relación.

## 5. Diagramas técnicos
Un diagrama debe ser comprensible sin una explicación excesiva. Procura:
- Identificar los elementos.
- Evitar cruces innecesarios de líneas.
- Mantener una dirección de lectura.
- Usar etiquetas breves.
- Diferenciar visualmente categorías.

## 6. Actividad principal: diagrama de una red de aula
Crea una diapositiva que represente una red local de aula con:
- Router o conexión de salida.
- Switch.
- Al menos cuatro ordenadores.
- Una impresora de red.
- Conexiones entre los dispositivos.
- Etiquetas para identificar cada elemento.

En otra diapositiva incorpora una imagen relacionada con una red o un armario de comunicaciones. Recórtala para centrar el elemento importante y añade una breve leyenda.

## 7. Reto de ampliación
Crea dos versiones del diagrama:
- Una con imágenes o iconos.
- Otra utilizando formas básicas.

Compara cuál resulta más fácil de modificar y cuál comunica mejor las conexiones. Justifica tu elección.
