# S12 - Exportación y publicación de presentaciones

> **Módulo:** Aplicaciones Ofimáticas · 1.º SMR  
> **Unidad didáctica:** UD4 - Presentaciones multimedia  
> **Duración:** 55 minutos  
> **Estado:** Preparado · Pendiente de impartir

## Objetivos de aprendizaje
- Comprender los conceptos y procedimientos explicados.
- Aplicarlos en LibreOffice Impress.
- Comprobar el resultado en modo presentación.
- Justificar las decisiones tomadas.

## Desarrollo teórico

## 1. Guardar y exportar
**Guardar** conserva el documento de trabajo para seguir editándolo. **Exportar** genera una versión destinada a otro uso o formato.

Conserva siempre el archivo original ODP, aunque también entregues un PDF.

## 2. Formatos habituales
| Formato | Finalidad | Consideración |
|---|---|---|
| ODP | Edición en Impress | Formato editable de trabajo |
| PDF | Lectura y distribución | No conserva la experiencia interactiva de la presentación |
| PPTX | Intercambio con PowerPoint | Pueden existir diferencias de compatibilidad |

No supongas que fuentes, multimedia y efectos se comportarán exactamente igual en todas las aplicaciones.

## 3. Exportar a PDF
1. Guarda primero el ODP.
2. Utiliza **Archivo > Exportar como > Exportar directamente a PDF** o la opción equivalente.
3. Revisa las opciones disponibles.
4. Guarda el PDF.
5. Ábrelo y revisa todas las páginas.

Comprueba que no haya texto cortado, imágenes incorrectas, páginas inesperadas o cambios de orden.

## 4. Preparar la entrega
```text
Entrega/
├── presentacion.odp
├── presentacion.pdf
└── recursos/
```
El ODP permite modificar el trabajo; el PDF facilita su consulta.

## 5. Publicar con responsabilidad
Revisa los datos personales, los permisos de uso de imágenes y sonidos y los nombres de archivo. Entrega únicamente las versiones finales y comprueba que el destinatario puede abrirlas.

## Actividad práctica

# Actividad: paquete de publicación
Utiliza una presentación desarrollada en sesiones anteriores.
1. Guarda la versión editable en ODP.
2. Exporta una copia PDF.
3. Abre el PDF y revisa todas las páginas.
4. Corrige los problemas detectados.
5. Organiza los archivos con nombres claros.

**Entrega:**
```text
Apellido_Nombre_UD4/
├── Presentacion.odp
└── Presentacion.pdf
```
Añade una nota indicando qué formato recomendarías para editar y cuál para distribuir.

## Ampliación
Ampliación: exporta también a PPTX si está disponible. Vuelve a abrirlo y anota las diferencias que observes respecto al ODP.

## Comprobación de aprendizaje
1. ¿Qué herramienta o concepto has aprendido?
2. ¿Qué decisión has tomado para mejorar la comunicación?
3. ¿Qué problema has detectado y cómo lo has resuelto?
4. ¿Qué comprobarías antes de mostrar el trabajo a otras personas?

## Criterios de calidad
- El archivo se abre y se puede editar.
- El diseño facilita la comprensión.
- Los recursos se utilizan con una finalidad.
- Se comprueba el resultado en modo presentación.
- La entrega está organizada.
