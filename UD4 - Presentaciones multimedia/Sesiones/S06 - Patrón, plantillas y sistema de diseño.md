# S06 - Patrón, plantillas y sistema de diseño

## Objetivos
Comprender la finalidad del patrón de diapositivas, distinguir patrón, diseño y plantilla, y construir una base reutilizable para una presentación técnica.

## 1. ¿Por qué necesitamos un sistema de diseño?
Cuando una presentación tiene muchas diapositivas, aplicar manualmente el mismo formato a cada una resulta lento y produce inconsistencias. Un sistema común permite modificar elementos globales de forma más eficiente.

## 2. Diferencias entre conceptos
- **Diseño de diapositiva:** distribución de los marcadores de posición en una diapositiva, por ejemplo título y contenido.
- **Patrón de diapositivas:** estructura maestra que permite controlar elementos y estilos compartidos por las diapositivas que dependen de ella.
- **Plantilla:** archivo o modelo reutilizable que puede incluir patrones, diseños, estilos y contenido de ejemplo.

No son términos intercambiables: el diseño organiza una diapositiva; el patrón establece reglas comunes; la plantilla permite reutilizar una configuración de presentación.

## 3. Ventajas del patrón
Puede servir para establecer:
- Tipografía de títulos y cuerpo.
- Colores de la presentación.
- Fondo.
- Posición de logotipo.
- Pie, numeración u otros elementos comunes.
- Diseños reutilizables para distintos tipos de contenido.

Si modificas un elemento compartido en el patrón, el cambio puede reflejarse en las diapositivas que utilizan ese patrón.

## 4. Planificación antes de editar el patrón
Antes de abrir el patrón, decide:
1. Qué elementos deben aparecer en todas las diapositivas.
2. Qué elementos solo deben aparecer en la portada.
3. Qué diseños necesitas: título, contenido, dos columnas, imagen y texto, cierre.
4. Qué colores y tipografías utilizarás.
5. Qué elementos deben poder modificarse en cada diapositiva.

No introduzcas en el patrón elementos que deban cambiar continuamente.

## 5. Actividad principal: crear una plantilla para el aula
Crea una presentación nueva titulada **«Plantilla técnica - 1.º SMR»**.

Diseña al menos tres tipos de diapositiva:
- Portada.
- Título y contenido.
- Dos columnas o imagen y texto.

Configura en el patrón, cuando la versión instalada lo permita:
- Fondo común.
- Estilo de títulos.
- Estilo del texto de contenido.
- Elemento gráfico o pie discreto.

Comprueba que las diapositivas nuevas utilizan los diseños previstos y que un cambio global se refleja correctamente.

Los nombres de menús y el acceso al patrón pueden variar según la versión de LibreOffice instalada. Si no encuentras la opción, consulta el menú Ver o las opciones de patrón/diseño disponibles en tu versión.

## 6. Reto de ampliación
Crea una segunda variante de diseño para una diapositiva de comparación. Mantén la misma paleta y tipografía, pero cambia la distribución. Explica qué decisiones se mantienen y cuáles cambian.

## 7. Entrega
Archivo `Plantilla_tecnica_Apellido_Nombre.odp`. Debe contener los diseños creados y una diapositiva de prueba de cada tipo.

## 8. Preguntas
1. ¿Qué diferencia hay entre diseño, patrón y plantilla?
2. ¿Qué elementos conviene establecer en el patrón?
3. ¿Qué problema puede aparecer si colocas en el patrón un elemento que debe cambiar en cada diapositiva?
4. ¿Por qué una plantilla mejora la eficiencia y la coherencia?
5. ¿Qué comprobarías antes de reutilizar una plantilla en otra presentación?
