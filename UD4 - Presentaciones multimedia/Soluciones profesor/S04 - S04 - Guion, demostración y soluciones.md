# S04 - Guion del profesor: imágenes y recursos gráficos

## Intención didáctica
Que el alumnado seleccione y trate recursos visuales con criterio, no que inserte imágenes de forma indiscriminada. Introducir el uso de diagramas para comunicar relaciones técnicas.

## Temporalización
| Tiempo | Desarrollo |
|---|---|
| 0-5 | Comparar imagen pertinente e imagen decorativa. |
| 5-15 | Explicar resolución, proporción, recorte, encuadre y licencias. |
| 15-25 | Demostrar insertar, redimensionar, recortar y añadir formas/conectores. |
| 25-43 | Construir el diagrama de red de aula. |
| 43-50 | Reto: comparar diagrama con iconos y con formas. |
| 50-55 | Revisión y preguntas. |

## Demostración
Insertar una imagen desde archivo. Mostrar la diferencia entre cambiar el tamaño del objeto y recortar la imagen. Redimensionar desde una esquina y explicar la deformación. Crear rectángulos para dispositivos y conectores para enlaces.

## Solución orientativa
Diagrama mínimo: router conectado al switch; switch conectado a cuatro equipos y una impresora. Aceptar otros esquemas si representan correctamente las conexiones propuestas. La imagen de apoyo debe tener relación directa con el tema y una leyenda.

## Evaluación
RA7.c y RA7.e. Comprobar la pertinencia de los recursos, la legibilidad de las etiquetas y la claridad del diagrama.
