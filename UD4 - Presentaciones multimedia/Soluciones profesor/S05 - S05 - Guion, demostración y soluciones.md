# S05 - Guion del profesor: color, contraste y consistencia

## Intención didáctica
Introducir el color como sistema de codificación visual. El objetivo es que el alumnado pueda explicar por qué utiliza una combinación y mantenerla con coherencia.

## Temporalización
| Tiempo | Desarrollo |
|---|---|
| 0-5 | Comparar dos diapositivas con contrastes distintos. |
| 5-15 | Explicar paleta, color principal, secundario, acento y neutros. |
| 15-25 | Demostrar cambios de fondo y texto y comprobar contraste. |
| 25-43 | Diseñar sistema visual para ciberseguridad. |
| 43-50 | Prueba de lectura entre compañeros. |
| 50-55 | Conclusión y ticket de salida. |

## Explicación clave
El color no debe ser el único medio para transmitir una categoría. Una advertencia debe tener también etiqueta, icono o posición diferenciada. Evitar fondos complejos detrás del texto. Una paleta limitada facilita coherencia y reduce decisiones repetidas.

## Solución orientativa
No hay paleta única. Evaluar:
- Función asignada a los colores.
- Contraste texto/fondo.
- Consistencia entre diapositivas.
- Uso moderado del color de acento.
- Comprensión sin depender exclusivamente del color.

## Evaluación
RA7.c y RA7.e. La explicación de la paleta es parte de la evidencia.
