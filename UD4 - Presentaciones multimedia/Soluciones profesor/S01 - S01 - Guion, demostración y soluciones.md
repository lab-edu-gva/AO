# S01 - Guión del profesor: entorno de trabajo y arquitectura

## Intención didáctica
El alumnado ya tuvo un contacto muy básico con Impress. Evitar una clase completa de botones. Utilizar la operación básica como punto de partida para introducir planificación, formatos y organización profesional del archivo.

## Temporalización (55 minutos)
| Tiempo | Desarrollo |
|---|---|
| 0-5 | Pregunta inicial: ¿qué hace que una presentación sea útil para quien la escucha? |
| 5-15 | Explicar audiencia, objetivo, mensaje y estructura. |
| 15-25 | Recorrido por la interfaz y formatos ODP/PDF/PPTX. |
| 25-32 | Demostración de creación, guardado, Guardar como y exportación PDF. |
| 32-48 | Actividad: guion y esqueleto de red local de aula. |
| 48-53 | Reto: exportar PDF y comparar con ODP. |
| 53-55 | Ticket de salida: una diferencia entre archivo editable y PDF. |

## Explicación que conviene desarrollar
Insistir en que el programa es una herramienta y no sustituye la planificación. Antes de crear diapositivas hay que definir destinatario, objetivo y mensaje. Una exposición técnica para compañeros no tiene la misma profundidad que una presentación para un cliente.

Explicar que el archivo ODP es el original editable. El PDF es una salida fija útil para distribución. PPTX es un formato de intercambio, pero pueden variar fuentes, objetos o efectos entre programas.

## Demostración guiada
Crear un archivo con nombre correcto en una carpeta de trabajo. Mostrar el panel de diapositivas, área de trabajo, panel lateral y barra de estado. Guardar, cerrar y volver a abrir. Exportar una copia PDF y mostrar que el contenido se visualiza, pero no se edita como los objetos de Impress.

## Solución orientativa
Guion posible:
1. Portada: red local del aula.
2. Objetivo: identificar los dispositivos y su función.
3. Esquema general.
4. Router y salida a otras redes.
5. Switch y conexiones internas.
6. Equipos finales e impresora.
7. Recorrido de los datos.
8. Resumen.

Se acepta otro orden justificado. Evaluar que exista un objetivo, una audiencia y una secuencia lógica.

## Evaluación
RA7.a y RA7.e. Evidencias: archivo ODP, PDF y guion previo.
